# Support

## Questions and bugs

Open an issue in the GitHub repository. Include your platform, app version, steps to reproduce and what you expected. Attach redacted diagnostics only.

## Security

Report security problems privately through the maintainer contact listed on the GitHub repository, not in a public issue. Do not attach credentials, sessions or tokens.

## Sponsorship

Sponsorship would fund cross-platform testing hardware and time, protocol maintenance against Telegram source drift, accessible interfaces and reliable signed releases. Sponsorship options will be listed here when they are available. No adoption, funding or endorsement claims are made.
