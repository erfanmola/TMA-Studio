# Privacy

## This website

The website is static. It loads no third-party scripts, fonts, analytics or trackers, and it sets no cookies.

## The app

- Account sessions and bot tokens are designed to stay in the host process and protected system credential storage (Keychain, Credential Manager, Secret Service where qualified), separate from Mini App browser data.
- Simulated outcomes and real Telegram actions are separate modes; mock storage is local simulation.
- Clearing Mini App site data never clears account vault or project records.
- Screenshots exclude secrets and developer tools by default.

## Reporting problems

Never include bot tokens, Telegram sessions, phone identifiers or unredacted launch data in issue reports, captures or exports.
